# 🏗️ СтройМаркет

Интернет-магазин строительных материалов. Цемент и сухие смеси, кирпич и блоки, пиломатериалы, краски и инструмент — всё для ремонта и строительства в одном месте. Удобный каталог, быстрый поиск, доставка на объект или самовывоз.

👤 **Автор:** _ФИО, группа_

## ✨ Возможности

### 🛒 Для покупателя
- 📦 Каталог из 16 товаров в 5 категориях.
- 🔎 Поиск по названию и бренду, фильтры по категории, цене и наличию, сортировка.
- 🧺 Корзина: изменение количества с учётом остатка на складе, удаление товаров, автоматический подсчёт суммы.
- 🚚 Доставка (500 ₽, бесплатно от 10 000 ₽) или самовывоз (бесплатно, на выбор два пункта выдачи).
- 📝 Регистрация и вход с проверкой полей и понятными подсказками об ошибках.
- 👤 Личный кабинет: редактирование данных, список заказов со статусами, отмена нового заказа.

### 🛠️ Для администратора
- 📊 Статистика: количество заказов, выручка, число товаров и покупателей.
- 📋 Заказы: просмотр и смена статуса (новый, в работе, выполнен, отменён). При отмене товары возвращаются на склад.
- 🧱 Товары: добавление, редактирование и удаление.
- 👥 Пользователи: список учётных записей и блокировка доступа.

### 🔐 Безопасность доступа
- Кабинет и админ-панель открываются только после входа.
- Покупатель не попадает в админ-панель, администратор — в кабинет покупателя.
- Авторизованному пользователю нельзя войти повторно, пока он не выйдет.
- Войти могут только зарегистрированные пользователи.

### 📱 Адаптивность
Сайт одинаково удобно работает на компьютере, планшете и телефоне.

├── style.css                                 — стили

## 🚀 Как открыть

Скачайте проект и откройте файл `index.html` в браузере. Устанавливать ничего не нужно.

🌐 Онлайн-версия работает через GitHub Pages: `https://<ваш-логин>.github.io/<название-репозитория>/`.

## 🖼️ Фото товаров

Фото лежат в папке `images/` и называются по номеру товара: `1.webp`, `2.webp` и так далее. Чтобы заменить фото, положите файл с нужным номером в эту папку. Для товара без фото показывается иллюстрация его категории.
